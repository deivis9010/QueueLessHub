# Testing Requirements

Before writing or changing tests, read `docs/skills/TESTING-REQUIREMENTS.md` and consult `src/tests/README.md` or `src/tests/FIXTURES_GUIDE.md` when relevant.

Add behavior-focused tests for changed behavior, covering success and failure paths. Reuse project fixtures and helpers, and run the narrowest relevant test first.
