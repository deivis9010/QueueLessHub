# API Design Rules

Before designing or changing an endpoint, read `docs/skills/API-DESIGN-RULES.md` and check the existing route and controller patterns.

Keep routes declarative, controllers focused on HTTP concerns, and business logic in services. Preserve established response shapes and document behavior changes where appropriate.
